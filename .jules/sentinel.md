## 2024-06-25 - Prevent SVG XSS and DoS in React Dropzone & Text Inputs
**Vulnerability:** The `react-dropzone` input allowed all image types (`image/*`), which includes SVGs. Malicious SVGs can contain executable JavaScript, leading to Cross-Site Scripting (XSS) when rendered in the UI. Additionally, unbounded `textarea` inputs pose a Denial of Service (DoS) risk if flooded with massive strings.
**Learning:** Generic wildcards like `image/*` are dangerous when used in file upload or drag-and-drop components without server-side validation or safe UI rendering (which React doesn't natively do for user-uploaded SVGs rendered directly). Text inputs without `maxLength` can crash the UI or cause excessive backend processing overhead.
**Prevention:** Explicitly define safe MIME types in dropzone config, e.g., `accept: { 'image/jpeg': [], 'image/png': [], 'image/webp': [] }`. Always add a reasonable `maxLength` attribute to text inputs and textareas to mitigate DoS vectors.
