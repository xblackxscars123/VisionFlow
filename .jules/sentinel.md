## 2025-02-26 - [Missing Input Limits and Raw Error Leakage in Frontend Pipeline]
**Vulnerability:** The VisionFlow app allowed unbounded file uploads and text inputs, which could be processed client-side leading to Memory Exhaustion / Client-Side DoS via the Canvas API. Additionally, caught errors were directly exposing `err.message` to the UI, which could leak internal implementation details or stack traces to end users.
**Learning:** Client-side heavy apps (like those doing image processing via Canvas or calling AI endpoints directly) must still perform strict input validation (file size and text length limits) to protect the client's device and the outbound network requests. Error handling must always sanitize messages before displaying to the UI, even if it's "just the frontend".
**Prevention:** Always set `maxSize` on file dropzones and `maxLength` on text areas. Always use a generic fallback message in `catch` blocks for UI display while logging the raw error securely if needed.
