## 2025-03-08 - [SVG-based XSS through Generic Image Uploads]
**Vulnerability:** The application was accepting `'image/*'` in its `react-dropzone` configuration for file uploads. This overly broad MIME type wildcard allows malicious `.svg` files containing embedded `<script>` tags to be uploaded and potentially executed by users, leading to Stored XSS if the SVG is subsequently displayed in the application or accessed directly.
**Learning:** Generic file type matchers like `image/*` should not be trusted for client-side security filtering because formats like SVG are essentially XML documents capable of executing arbitrary JavaScript. Relying on the browser or React alone to sanitize SVGs dynamically rendered as images isn't always reliable.
**Prevention:** Always explicitly allowlist the specific, safe MIME types (e.g., `image/jpeg`, `image/png`, `image/webp`) expected by the system logic rather than using wildcards, especially in upload boundaries and dropzone properties.
