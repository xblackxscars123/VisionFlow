## 2026-46-21 - Focus-within for Hover Revealed Actions\n**Learning:** When using Tailwind's `group-hover:opacity-100` to hide actions until hovered (like the download button over the result image in App.tsx), keyboard users will tab into invisible elements. They focus on the button, but it remains invisible.\n**Action:** Always pair `group-hover:opacity-100` with `group-focus-within:opacity-100` on the parent container. This ensures that when a keyboard user tabs to an inner element, the parent container reveals its contents.
