## 2024-08-26 - [Keyboard Accessibility for Hover-Revealed Actions]
**Learning:** In the React application, secondary actions (like download buttons on image assets) are hidden by default using `opacity-0` and revealed on hover (`group-hover:opacity-100`). This pattern breaks keyboard accessibility because tabbing to the hidden button doesn't trigger the container's hover state, leaving the focused button invisible to the user. Adding `focus-visible` to the button itself isn't enough if its parent container remains at zero opacity.
**Action:** When using `group-hover:opacity-100` to reveal interactive elements, always pair it with `group-focus-within:opacity-100` on the parent container. This ensures the container becomes visible when any of its child elements receive keyboard focus, allowing the user to see what they are interacting with. Also, always ensure icon-only buttons receive an `aria-label` and `title`.
