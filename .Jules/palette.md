## 2023-10-27 - Keyboard Navigation in Hover States\n**Learning:** When using Tailwind's hover states (like `group-hover:opacity-100`) to reveal interactive elements (e.g., download buttons over images), they become inaccessible to keyboard users because the element cannot be seen or focused when tabbing through the page.\n**Action:** Always pair `group-hover:opacity-100` with `group-focus-within:opacity-100` on the parent container to ensure the interactive elements remain visible and accessible via keyboard navigation. Additionally, ensure icon-only buttons receive clear `aria-label` attributes and visible focus states (e.g., `focus-visible:ring-4 focus-visible:ring-orange-500 focus:outline-none`).
