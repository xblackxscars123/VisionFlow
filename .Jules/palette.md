## 2024-08-22 - Download Button Keyboard Accessibility\n**Learning:** In Tailwind, relying solely on `group-hover` for revealing interactive elements hides them from keyboard-only users. When adding `group-hover:opacity-100`, it must be paired with `group-focus-within:opacity-100` on the container to ensure the button can be tabbed to.\n**Action:** Always test hover-revealed interactive UI elements with keyboard navigation and apply `group-focus-within` alongside `group-hover` patterns.
