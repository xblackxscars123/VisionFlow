## 2023-10-25 - [Accessibility Issue Pattern: Hover-Only Overlays]
**Learning:** Found a recurring pattern in App.tsx where crucial interactive elements (like the download button for optimized images) were placed inside parent containers using `group-hover:opacity-100` to reveal them. While visually clean for mouse users, this completely breaks keyboard accessibility because the elements remain visually hidden (opacity 0) when tabbed to, even if they technically receive focus.
**Action:** When using `group-hover:opacity-100` to reveal interactive elements, always pair it with `group-focus-within:opacity-100` on the parent container. This ensures the interactive elements remain visible and accessible via keyboard navigation. Additionally, always add explicit `focus-visible` ring styling to the revealed buttons.
